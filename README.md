# Livo PR Demo

《蒂利亚之冬》的可点交互演示。这个仓里只有静态导出产物，源码在 Livo 世界主工程里。

**在线地址：** https://mrhanjk2010.github.io/livo-pr-demo/ （永远进最新一版）

手机尺寸的界面装在一个 375×812 的框里，框外左右两侧是演示用的旁注（左：剧情脚本，右：版本、图层与剧情节点切换）。这两块只在演示时存在，不属于产品 UI。

在框右侧「演示控制 · 演示版本」里可以直接换版本，两个方向都通。每版是一次完整的静态导出（自带 `_next` 与图片），版本之间不共享资源 —— 只有这样旧版才真的还是旧版。

## 这版演示看什么

演示的主线是**一句话如何在世界里长出结果**，从 `/tilia/map` 进去：

| 顺序 | 在哪 | 看什么 |
| --- | --- | --- |
| 1 | 世界动态卡 · 「回应这一刻」 | 说一句话，15 秒后世界给出回响，地图上落下新的潜在命运 |
| 2 | 音乐厅命运 → 茶室 | 聊到小提琴，茶室随后多出一把琴，最后送到你手上 |
| 3 | 右侧「一周后」 | 时间推进，巡警检查等三枚命运出现；琴里藏着 XK-101，帮你躲过开箱 |
| 4 | 检查散场 | 你向任轻义问起车头，他答应替你递话 —— 地图补上驾驶车厢 |
| 5 | 世界动态卡（整张可点） | 全屏世界动态页，按天分组，每条动态有展开后的完整内容 |
| 6 | 动态卡右上那枚呼吸光点 | 全屏**世界回响星图**：可四向拖动的画布，点一枚回响看它由哪些事件与时机汇聚而成 |

## 几处刻意的设计

- **新出现的东西不是世界临时造的。** 琴、驾驶车厢，都被写成「一直在，只是之前进不去/没人提」—— 是你的话被人听见了，才有人递琴、开门。
- **因果是可回溯的。** 命运聊天里有「事后回指」的卡片，把当下这一刻串回最初那句话；回响星图是同一件事的另一种看法 —— 不是列表，是一张星图。
- **星图里有很多接不上线的光点。** 世界发生的事本来就多于结出果的事，全屏里每个光点都能接上线反而假。

## 构建方式

主工程里跑：

```bash
VERSION=v3 REPO=livo-pr-demo bash scripts/deploy-pages.sh "提交说明"
```

脚本负责静态导出（含 `basePath` 改写、`.nojekyll`、绕开并行路由的那几个坑）、同步产物到 `<版本>/`、改写根跳转页、提交并推送。发新版前记得在源码里的 `src/lib/demo-versions.ts` 添一条登记，切换器才列得出它。细节都写在脚本注释里。
